
# Quadratic Equation Solver

Консольний розв'язувач квадратних рівнянь на Node.js,
запущений у Docker-контейнері.

## Можливості
- Обчислення дискримінанта.
- Знаходження двох дійсних коренів.
- Знаходження одного подвійного кореня.
- Повідомлення про відсутність дійсних коренів.
- Передача коефіцієнтів через змінні середовища.

## Запуск

Збірка Docker-образу:

```bash
docker build -t quadratic-solver .
```

Запуск контейнера:

```bash
docker run --rm -e A=1 -e B=-5 -e C=6 quadratic-solver
```
